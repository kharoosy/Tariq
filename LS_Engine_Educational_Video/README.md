# GM LS V8 — Open Loop vs Closed Loop · فيديو تعليمي ثلاثي الأبعاد بالعربي (120 ثانية)

A fully procedural, open-source production: Blender (Cycles, via the `bpy` module) for the 3D engine,
Piper neural TTS for the Arabic narration, Python/Pillow for motion graphics, FFmpeg for mastering.
No paid tools, no third-party models, no third-party audio.

## Rebuild

```bash
sudo apt-get install -y ffmpeg fonts-noto-core libegl1      # system deps (Ubuntu 24.04)
python3.13 setup.py --install                               # pip deps + Piper Arabic voice + Whisper QA model
python3.13 render_all.py --preview                          # ~10 min animatic (every 10th frame)
python3.13 render_all.py                                    # full quality, ≈6 h on 4 CPU cores
```

Rendering is resume-capable: re-running `render_all.py` (or `03_Blender/render_scenes.py`) skips frames
that already exist. With a GPU, set `scene.cycles.device = 'GPU'` in `03_Blender/create_scenes.py`
and raise resolution to 1920×1080 / samples to 16+ in `QUALITY['final']`.

## Editing

* **Engine geometry / materials / studio** – `03_Blender/build_engine.py`
* **Motion** (crank, valves, injection timing, flow, camera path, colour/state timeline) –
  `03_Blender/animate_engine.py` (`CAM_KEYS`, `env()`, `apply_frame()`)
* **Open the .blend in Blender 4.2+/5.x**: run the text block `register_handler.py` (Text editor → Run
  Script) to register the per-frame animator, then scrub the timeline.
* **Narration text / scene timing** – `01_Project/scene_timeline.json` (fields `tts` = fully vocalised
  text sent to the voice, `sub` = subtitle text), then `generate_narration.py`.
* **On-screen graphics & subtitle style** – `assemble_video.py`.
* **Music / SFX / mix levels** – `generate_audio.py`.
